# NandKitchen 🍽️

A simple recipe website built as part of The Odin Project curriculum.

## About

NandKitchen is a recipe website featuring a collection of favourite recipes and food inspiration.

## Features

- Homepage with favourite recipes
- Individual recipe pages
- Recipe images and descriptions
- Recipe discovery by category

## Technologies Used

- HTML

## What I Learned

- Creating HTML page structures
- Adding links between pages
- Displaying images using relative file paths
- Organising project files and folders
- Using Git and GitHub for version control

## Project Status

In progress. More features and styling will be added as I learn CSS and JavaScript.
